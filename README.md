# project-fps

Welcome to Project FPS. This is a base game or a core framework that aims to let developers and/or game development enthusiasts make their own 3D FPS style games in Godot. While this project is optimized for FPS games in general, it can also be partially or completely used for other genres and games. This project includes:

1. A Player Controller that lets the player move and look around, jump, crouch, and sprint without any physics bugs
2. A Scene Manager and Save/Load System that handles the saveable objects, the save loading system dedicated to the game and scene transitions
3. A Pickup System that lets the player pick up the physics objects and throw them without any known game-breaking bugs (like prop climbing, wall climbing, etc)

This project includes third-party digital assets (including 3D models, textures, sound effects, and animations) obtained from open platforms under their respective free and attribution-friendly licensing terms. These assets are integrated solely for demonstration, testing, and aesthetic representation. They do not constitute the core functionality or original codebase of the framework. A credit list is formally documented in the LICENSINGINFO.md file included in this repository.
