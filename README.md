# project-fps

Welcome to Project FPS. This is a base game or a core framework that aims to let developers and/or game development enthusiasts make their own 3D FPS style games in Godot. While this project is optimized for FPS games in general, it can also be partially or completely used for other genres and games. This project includes:

1\. A Player Controller that lets the player move and look around, jump, crouch, and sprint without any physics bugs
2\. A Scene Manager and Save/Load System that handles the saveable objects, the save loading system dedicated to the game and scene transitions
3\. A Pickup System that lets the player pick up the physics objects and throw them without any known game-breaking bugs (like prop climbing, wall climbing, etc)
4\. An Interaction System that lets the player interact with different interactable objects like doors, buttons and keys that are kept with the player key inventory
5\. Object Movement Scripts that can move and turn objects with assigned points as targets or anchors
6\. Player Sounds like footsteps depending on surface tag, jump and land sounds
7\. Player Stats like health, optional armor, oxygen, and stamina that all can be managed
8\. Special Objects for various things such as a flashlight object, a health/armor pick up objects, breakable objects, crates, explosive barrels, etc
9\. Visual Effects for various use cases like fire, explosion, electricity, rain, and snow
10\. A Logic System with triggers that can take different condition parameters like LogicCompare, LogicTimer, LogicGate etc for storytelling and logic
11\. Physics Objects and Systems for immersive physics puzzles and showcases with physics objects, liquids, cloths and ropes
12\. A Weapon System with 8 different weapons that all have different features and good animations with Inverse Kinematics (IK)
13\. A NPC System with friendly/hostile NPCs with different and responsive behaviours, face animations with code, and animation with Inverse Kinematics (IK)
14\. An Achievement System with Steamworks integration
15\. UI and menus that handle the settings, chapters, and more

This project includes third-party digital assets (including 3D models, textures, sound effects, and animations) obtained from open platforms under their respective free and attribution-friendly licensing terms. These assets are integrated solely for demonstration, testing, and aesthetic representation. They do not constitute the core functionality or original codebase of the framework. A credit list is formally documented in the LICENSINGINFO.md file included in this repository.
